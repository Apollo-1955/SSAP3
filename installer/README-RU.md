# Установка SoundStage

Публичная сборка распространяется одним файлом `SoundStage-Setup.exe`. Внутри
находятся приложение, драйвер Apple AAP, пространственный аудиодвижок, компоненты
для безопасного удаления и все необходимые лицензии.

## Установка

1. Подключите AirPods к Windows.
2. Отключите Secure Boot в UEFI/BIOS.
3. Запустите `SoundStage-Setup.exe` и подтвердите запрос администратора.
4. Перезагрузите Windows, когда установщик попросит.
5. После загрузки ещё раз запустите тот же `SoundStage-Setup.exe`.

На первом этапе установщик проверяет пакет, сохраняет копию BCD, при
необходимости временно приостанавливает BitLocker на одну перезагрузку и
включает Windows Test Mode. На втором этапе устанавливаются приложение,
тестово подписанный драйвер и пространственный движок.

Старые тестовые сборки автоматически мигрируют: настройки сохраняются, старые
драйверы и сертификаты удаляются, а исходные аудиоэффекты корректно
восстанавливаются перед подключением SoundStage.

## Качество звука и микрофон

Для качественного звука выберите `AirPods Stereo`. Bluetooth не умеет
одновременно передавать качественный A2DP Stereo и микрофон AirPods. Для
Discord и игр используйте отдельный USB- или встроенный микрофон.

## Удаление

Откройте **Параметры Windows → Приложения**, выберите **SoundStage** и нажмите
**Удалить**. Удаление восстанавливает исходные аудиоэффекты, удаляет драйвер,
сертификат, автозапуск и ярлыки, а также выключает Test Mode, если SoundStage
включил его при установке.

Подробные предупреждения и восстановление описаны в `INSTALL.md`.
